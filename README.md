Rock Paper Scissors Game (Stein, Saks, Papir)

A classic Rock, Paper, Scissors web application built with vanilla JavaScript, HTML, and CSS. Play against a randomized computer opponent, keep track of your scores, and test your luck!

Features:

Interactive Gameplay: Pick Rock, Paper, or Scissors to compete against the machine.
Score Tracking: Tracks Player Wins (Spiller), Machine Wins (Maskin), and Draws (Uavgjort).
Game Win/Loss Condition: First to reach 4 points wins the match!
Reset Functionality: Reset scores and restart the game at any time.
Timed Visual Reset: Choices reset automatically after 3 seconds for the next turn.

Tech Stack:

HTML5: Game layout and elements.
CSS3: Custom layout styling, hover effects, and responsive element sizes.
JavaScript (ES6+): Event listeners, randomized computer choices, score tracking, and DOM manipulation.

Project Structure:

.
├── main.html      # HTML layout for player choices, scores, and images
├── style.css      # Styling for buttons, layout, and images
├── main.js        # Main game logic and event listeners
└── assets/        # Image files (rock.png, paper.png, scissor.png, machine.png)


Getting Started:

No installation or build setup required.
Clone or download the repository:
git clone https://github.com/your-username/rock-paper-scissors.git


Navigate to the project folder:

cd rock-paper-scissors
Open main.html in your favorite web browser to play!

🎮 How to Play:

Click the Start Game button to initialize controls.
Select Rock, Paper, or Scissors by clicking on the respective option.
The computer will randomly generate its choice.
Watch the score update automatically! First to 4 points wins.
Click Reset to clear the scores and start over.
